# 背景音乐

把你想播放的音乐文件放到这个文件夹里。

## 重要：`.mgg` 不能直接用

当前文件夹里的 `CMJ-所念皆星河.mgg` 是 QQ 音乐加密格式，浏览器无法播放。

需要先把它转换成 `.mp3` 或 `.m4a`，或者另外找一份普通的 `.mp3` 音乐文件。

## 当前使用的文件

```
music/bgmusic.mp3
```

`data.js` 里的 `music.src` 已经指向这个文件。

## 建议

- 音乐文件使用 `.mp3` 或 `.m4a` 格式，兼容性最好
- 如果文件名不同，记得同步修改 `data.js` 里的 `music.src`
- 注意音乐版权：本网页会分享给学习小组，建议使用有授权或非商用的版本
